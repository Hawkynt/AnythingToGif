> A from-scratch GIF reader and writer with direct control over frames, palettes, delays and disposal, for when you need to build an animation rather than hand a bitmap to an encoder.

## 📦 Installation

```bash
dotnet add package Hawkynt.GifFileFormat
```

## ✨ Features

- Writes animated GIFs frame by frame, with per-frame palette, position, delay and disposal method.
- Reads existing GIFs back into the same frame model.
- Explicit control over the parts an encoder usually hides: colour resolution, global versus local colour tables, loop count, transparency index and interlacing.
- Optional LZW compression on write.

## 🧩 Types

- **ColorResolution**: Handles the color resolution settings for GIFs.
- **Dimensions**: Manages the width and height of the GIF.
- **Frame**: Represents individual frames within a GIF.
- **FrameDisposalMethod**: Handles how frames are disposed of when a new frame is drawn.
- **LoopCount**: Manages the looping behavior of GIFs.
- **Offset**: Handles the offset values for GIF frames.
- **Writer**: Provides methods to write or save GIF files.

## 🚀 Quick start

Write a two-frame animation that loops forever:

```csharp
using System.Drawing;
using Hawkynt.GifFileFormat;

var size = new Dimensions(64, 64);
var palette = new[] { Color.Black, Color.Red };

var frames = new[] {
  new Frame(indexedPixels: firstFrameIndices, size, Offset.None, localColorTable: null,
            delay: TimeSpan.FromMilliseconds(100), FrameDisposalMethod.DoNotDispose,
            transparentColorIndex: null),
  new Frame(indexedPixels: secondFrameIndices, size, Offset.None, localColorTable: null,
            delay: TimeSpan.FromMilliseconds(100), FrameDisposalMethod.DoNotDispose,
            transparentColorIndex: null),
};

Writer.ToFile(
  new FileInfo("animation.gif"),
  size,
  frames,
  loopCount: LoopCount.Infinite,
  globalColorTable: palette,
  allowCompression: true);
```

Pixels are **palette indices**, not colours — one byte per pixel, indexing the global or local colour table.

## 🔌 Dependencies

Requires `System.Drawing` for the `Color` type.

## ⚠️ Limitations

- Frames are supplied as indexed pixels. This package does no quantization: turning true-colour images into palette indices is the caller's job (the parent [AnythingToGif](https://github.com/Hawkynt/AnythingToGif) tool does it).
- A palette holds at most 256 entries, per the GIF format itself.
- `allowCompression` defaults to `false`, so output is uncompressed unless asked otherwise.
